## ✨ Why Misty?

| | |
|---|---|
| 🪶 **Ultra light** | Written in Rust, Misty uses very little RAM, so the memory goes to the game, not the launcher. |
| 📦 **Every version** | Releases, snapshots, betas and alphas. |
| 👤 **Accounts** | Microsoft sign-in or offline accounts. |
| 🔄 **Auto updates** | Misty updates itself, no reinstall needed. |
| 🌍 **Multilingual** | Translated interface and Discord Rich Presence. |
| 🔗 **Shared libraries** | Files shared by profiles are downloaded only once. |

## 🧩 Mods, modpacks and profiles

- **Separate profiles**: each profile has its own version, mod loader and folder.
- **Modrinth & CurseForge**: mods, resource packs, datapacks and shaders, with automatic dependency handling.
- **Modpacks**: one-click import.
- **6 mod loaders, installed automatically**:

  `Forge` · `NeoForge` · `Fabric` · `Quilt` · `OptiFine` · `LiteLoader`

## 🧍 Skins and capes <sup>new in 0.3.2</sup>

A **SKIN** tab on the home page with a 3D character preview, PNG skin upload (64×64 or 64×32), classic (Steve) or slim (Alex) arms, and cape selection.

## 📥 Installation

| Format | Size | Description |
|---|---|---|
| **Installer** `.exe` *(recommended)* | 10.4 MB | Installs to your user profile, with a Start menu shortcut and a clean uninstall. |
| **Portable** `.zip` | 12.5 MB | No installation: just run `Misty.exe`. Great for a USB drive. |

> Free, for Windows 10 and 11. **No admin rights needed.**
