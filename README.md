# Misty Launcher

Misty Launcher is an all-in-one game launcher concept inspired by **misty-launcher.online**.

## What it focuses on

- One unified library for games across major platforms and local installs
- Fast game discovery with automatic scanning of installed titles
- Rich game pages with useful details before launch
- Social features like friends, chats, and multiplayer session planning
- Profile customization to showcase collections and achievements

## Vision

A lightweight, privacy-conscious launcher that helps players organize, discover, and play games from one place.
